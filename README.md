# AutoVault Vehicle Marketplace

Modern automotive vehicle marketplace featuring multi-criteria search, dynamic price filtering, and image galleries.

---

## 🚀 Tech Stack
`Next.js` `TypeScript` `Tailwind CSS` `PostgreSQL` `Prisma`

---

## ✨ Key Features
- **Advanced**: multi-parameter vehicle search (Make, Model, Year, Mileage, Transmission)
- **Dynamic**: price filtering with responsive sorting algorithms
- **Detailed**: vehicle specification pages with high-resolution image carousels
- **Dealer**: contact inquiry forms and test drive scheduling flow
- **Fully**: responsive, mobile-optimized UI with fluid animations

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+) or Python (3.10+) depending on project requirements
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/aqsam-husnain/autovault-marketplace.git

# Navigate into project directory
cd autovault-marketplace

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Run the development server
npm run dev  # or: python app.py
```
